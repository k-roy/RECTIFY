### 1b. Poly-A trim audit — COMPLETE

**Goal:** verify RECTIFY always trims to the first non-A base after detecting any
adapter stub, across all 36 validation reads.

**Audit shipped:**

- `scripts/validation_data/audit_polya_trim.py` (new, M1) — extracts the
  last 150 bp of each read in RNA 5'→3' orientation, calls
  `find_polya_and_adapter` from `drs_trim_command`, emits a TSV and
  flags four invariants (A: adapter detected + trim skipped;
  B: trim_applied + post-trim boundary is A — the "trim to first non-A"
  violation; C: Pass 2 triggered; D: no stub but raw_last_base non-A).
- Output: `validation_read_review/polya_trim_audit.tsv` (36 rows).

**Trap fixed in the audit:** the docstring for `find_polya_and_adapter`
calls its returned `last_base` a "quality check" — it is `window[-1]`,
i.e. the OUTERMOST base of the RNA window (= the last A of the pA tail
when one exists), NOT the post-trim boundary. Using it directly for the
"first non-A" check would fire 36/36 false positives. The audit
computes `post_trim_boundary = rna_window[:-(polya_len + len(adapter_seq))][-1]`
instead, which is the actual base immediately upstream of the cut.

**Results (M1, 2026-05-19):**

```
trim_applied (polya_len ≥ 1):                       36/36
pass 0 (Dorado already trimmed) / 1 / 2:            25 / 10 / 1
flag A (adapter detected, trim skipped):             0
flag B (trim_applied AND post_trim_boundary == A):   0   <-- invariant holds
flag C (Pass 2 triggered):                           1   (cat5_minus_1, adapter "CAATACC")
flag D (no-stub AND raw_last_base non-A):            0
source = dorado:             34
source = minimap2_fallback:   2   (cat1_plus_1, cat1_minus_1)
```

The "trim to first non-A" invariant is verified across the validation
set. The two `minimap2_fallback` reads came from a post-trim BAM
(`build_dorado_source.py` Phase 2) so their record is informational; the
invariant is satisfied for them too.
